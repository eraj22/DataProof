# Paper package

`main.tex` is an IEEE conference skeleton. The course brief requires the paper to be written by the student in their own words, so the sections intentionally contain authoring prompts rather than generated prose. Use `evidence_pack.md` and the saved result files for exact numbers. `references.bib` contains 30 preliminary entries derived from `reference_candidates.md`; verify every entry, cite only discussed work, then compile and check that the complete paper is 8-10 pages including references.

Before submission, replace the project-code placeholder, generate the PDF from this same source, and obtain both Turnitin reports for that final PDF.
