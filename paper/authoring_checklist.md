# Phase 2 paper authoring checklist

The course requires the student to write the paper in their own words. This file is an evidence and structure checklist, not a paper draft.

- [ ] Confirm assigned project code, student email, and supervisor feedback.
- [ ] Use IEEEtran or acmart, two columns, 8-10 pages including references.
- [ ] Abstract (150-250 words): fill quantitative claims only from saved results.
- [ ] Introduction: motivation, three fixed gaps, research questions, contributions.
- [ ] Related work: synthesize the Phase 1 review and verify every paper reference.
- [ ] Problem formulation: table, question, plan, answer, clarification/abstention.
- [ ] Method: architecture, planner, execution tool, verifier, decision controller.
- [ ] Experimental setup: fixed DSBench IDs, dev/test separation, exact Groq model, temperature, prompts, seed, hardware, costs.
- [ ] Evaluation methodology: shared metrics and whether DSBench base results were reproduced or quoted.
- [ ] Results: E1-E6, gap-resolution table, three repeats with mean and standard deviation.
- [ ] Ablations: switch off each gap component independently.
- [ ] Failure analysis: category frequencies, two success and two failure traces.
- [ ] Limitations and threats to validity; conclusion.
- [ ] 25-30 cited references, each DOI link or official URL if no DOI.
- [ ] Turnitin similarity and AI-writing reports generated on the final student-written PDF.
- [ ] Correct submission names, paper source ZIP, public/shared repository, `phase2-final` release.
